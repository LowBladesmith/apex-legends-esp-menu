## 🧩 About

**Apex Legends overlay Menu** is a curated list of Apex Legends open-source tools:

- **Overlays** — on-screen helpers, layout notes, loot tracker, map overlay
- **Quality-of-Life Helpers** — loadout catalog, legend notes, HUD layout notes
- **Research Notes** — drop layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Match Helpers
- Loot Tracker — highlight nearby loot for study
- Map overlay Notes — review rotations and drop zones
- Match Replay Notes — record and review runs
- Playback Speed — adjust demo playback for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Legend Catalog — browse legends, skins, banners
- Loadout Notes — organize weapon and attachment presets
- HUD Clarity — improved on-screen readability

### 🏋️ Practice Layout
- Firing Range Notes — segment study on any layout
- Movement Drill Notes — chain complex maneuvers in the range
- Config Presets — save and switch study configs
